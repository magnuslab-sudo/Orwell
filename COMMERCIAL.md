# Commercial licence and hosting

Orwell is free software under the GNU AGPL, version 3 only. For most people
that is all you need. You can use it, run it, change it and share it.

The AGPL has one rule that matters here. If you change Orwell and other people
use your changed version, over a network or as a copy you give them, you must
offer them your changed source code under the AGPL too.

If you cannot or do not want to do that, I sell a commercial licence. It is a
separate agreement with me, the copyright holder, and it lets you use Orwell
without the AGPL's conditions.

## You do not need it if

- you use Orwell for yourself, your friends or your community;
- you run your own server with the code as it is in this repository;
- you change the code and publish your changes under the AGPL.

## You probably need it if

- you run a modified server and want to keep your changes private;
- you want to put Orwell, or part of it, inside a closed product;
- your company does not allow AGPL code.

Not sure? Write to me and tell me what you want to do. I will give you a
straight answer. This page is a guide, not legal advice. The
[`LICENSE`](LICENSE) file is what counts.

## Hosting

If you would rather not run a server at all, I can run one for your
community. You get the same app and the same encryption. I look after the
server. The server still cannot read your messages, because that is how
Orwell is built, whoever runs it.
